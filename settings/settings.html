PageMind

Settings

AI Mode

Choose how PageMind connects to AI. Use Direct API if you have your own key, or Backend Server to route through a proxy.

AI Provider

Your API key is stored locally and used directly — it never goes through any intermediate server.

API Key

Stored in chrome.storage.local — never synced across devices or sent to third parties.

Get your free key at console.groq.com/keys

Backend Server

Point PageMind at your own backend or the default Render deployment. The backend handles AI calls server-side — no key needed in the extension.

Default: https://pagemind-backend.onrender.com (free tier, cold-starts in ~30s)

Cache

Summaries are cached per URL for 30 minutes to avoid repeat API calls.
